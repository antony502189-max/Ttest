| Возможность APK | До аудита | Итог |
|---|---|---|
| Onboarding и выбор языка | отсутствовал в web-shell | добавлен, сохраняется один раз |
| Мобильная главная APK-типа | частично | связана с реальными фильтрами и маршрутами |
| Четыре действия местоположения | неполно | все четыре работают |
| Поиск рядом | отсутствовал | добавлен с разрешением и координатами URL |
| Поиск по телефону | отсутствовал | добавлен и связан с карточкой |
| Отдельная карта/рисование | частично | карта, свободный контур, отмена и reload |
| Мобильные результаты | частично | фильтры, сортировка, фото, избранное, скрытие, контакт |
