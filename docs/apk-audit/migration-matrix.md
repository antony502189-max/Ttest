## Итог после реализации

Все конкретные P0/P1 gaps из этой pre-change матрицы закрыты: четыре location actions, Search this area, типизированные ошибки геолокации, nearby radius/URL, phone entry, единый mobile selector, polygon persistence, map/list/filter synchronization и разделение mobile/desktop map implementations.

Post-auth Idealista остаётся `not verified` из-за отсутствия внешних тестовых credentials; эквивалентные потоки сайта проверены demo-аккаунтами. Новые строки для восстановленных состояний локализованы на ES/EN/RU; legacy route-строки вне изменённого scope не выдаются за полностью централизованные.
