# Контракт поведения

- Существующие desktop/tablet экраны, фильтры и сортировки не переоформляются.
- Поддерживаются ровно три языка: испанский, английский и русский.
- Мобильные состояния имеют прямые URL, переживают reload и работают с Back.
- Выбор нескольких зон и официального района сохраняется в `zonas` и восстанавливается после reload.
- Административные зоны и нарисованный полигон взаимоисключающие.
- Геолокация запрашивается только после действия пользователя; отказ не ломает карту.
- Избранное, скрытые объявления, история, сохранённые поиски и сообщения разделены по пользователям.
- Контакт гостя ведёт в каноническую авторизацию.
- Публикация гостя показывает gate; авторизованный владелец попадает в существующий мастер.
- Секрет карты не хранится в git; production получает его из GitHub Actions secrets.
- При ошибке Google Maps остаётся доступная текстовая альтернатива.
