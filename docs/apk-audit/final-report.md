# Финальный отчёт APK → Web

Переданный APK запущен в Android Emulator и пройден как гостевой пользователь. Проверены первый запуск, главная, выбор местоположения, карта, поиск рядом и по телефону, нижняя навигация, меню и вход.

Авторизованные состояния APK нельзя было открыть без внешних учётных данных Idealista. Поэтому их соответствие проверено по доступным ресурсам APK и по функциональному контракту проекта, а работоспособность сайта — с предоставленными demo-аккаунтами. Протестированы вход/ошибка входа, регистрация, восстановление, профиль, публикация, редактирование, статусы, избранное, сохранённые поиски, локальные сообщения и административные действия.

Ключевые исправления:

- прямые мобильные URL и восстановление после reload;
- полный экран местоположения с четырьмя действиями APK;
- поиск рядом и по телефону;
- отдельные состояния карты и свободного рисования;
- мобильные результаты, фильтры и сортировка без изменения их состава;
- связь избранного, сообщений, аккаунта и публикации с общим AppContext;
- устранение расхождения между выбранными муниципалитетами/районами и URL;
- доступный fallback карты;
- responsive, accessibility и visual regression gates.

Сборка не содержит APK, декомпилированных ресурсов, `.env.local`, ключей, `node_modules`, тестовых видео и временных артефактов.
