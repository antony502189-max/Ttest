# Инвентаризация экранов APK Idealista

Референс проверен в Android Emulator из переданного `app.apk`: пакет `com.idealista.android`, версия 14.5.0.

| Область | Проверенный экран/состояние | Реализация сайта |
|---|---|---|
| Первый запуск | язык, страна, конфиденциальность, пропуск входа | мобильный onboarding, только ES/EN/RU и España (Tenerife) |
| Главная | Vivienda/Turismo, кто будет жить, местоположение, поиск, публикация | `MobileAppV2` |
| Местоположение | поиск адреса и четыре дополнительных действия | отдельный URL-state `panel=ubicacion` |
| Карта | просмотр объявлений, слои, геолокация, список, фильтры | отдельный полноэкранный map-state |
| Рисование | свободный контур, отмена, очистка/повтор | URL `vista=mapa&dibujar=1`, polygon сохраняется |
| Поиск по телефону | телефон, режим аренды, тип объекта, поиск | `panel=telefono`, переход к найденному объявлению |
| Результаты | список, сортировка, фильтры, карточки, фото, избранное, скрытие, контакт | связаны с общим каталогом и состоянием приложения |
| Нижние вкладки | Inicio, Búsquedas, Favoritos, Chat, Menú | реальные hash-маршруты |
| Публикация | gate до входа, мастер после входа | канонические `/acceso` и `/publicar` |
| Аккаунт | вход, регистрация, восстановление, профиль, выход | существующие route-based экраны сохранены |
| Кабинет | объявления, редактирование, статусы, сообщения, сохранённые поиски | существующий функционал сохранён и связан |

Скриншоты аудита эмулятора хранятся вне репозитория в рабочем каталоге аудита; APK и его ресурсы в репозиторий не добавляются.
