# Исправления платёжного аудита — 14 октября 2026

Проверены замечания BUG-001–007 из переданного PDF для ревизии `1c0c07c7`.
Рекомендация о слиянии с main не является частью исправления этих ошибок;
изменения выполняются в `feature/payments-promotions-ads`.

| Замечание | Исправление |
|---|---|
| BUG-001 | Подписанное `checkout.session.async_payment_failed` переводит заказ в `failed`; повторная покупка разрешена без выдачи услуги. Фоновая сверка проверяет финальный статус PaymentIntent при завершённой неоплаченной сессии. |
| BUG-002 | Удаление объявления владельцем или администратором блокируется при незавершённой оплате или действующих оплаченных правах. Сначала необходимо отменить оплату, дождаться окончания либо оформить возврат. |
| BUG-003 | Та же проверка выполняется до удаления аккаунта, объявления, кампании и фото. Финансовые факты и периоды сохраняются отдельно от объекта услуги. |
| BUG-004 | Сохраняются PaymentIntent, Charge, финансовое состояние и подтверждённая сумма возврата. Refund/dispute события дедуплицируются и сверяются с актуальным Stripe API. Возврат считается завершённым только по `succeeded`-квитанциям; pending/failed возвраты не выдаются за полученные деньги. |
| BUG-005 | Оплаченный rejected-баннер продолжает занимать своё место до исправления или завершённого возврата. Другая продажа не вытесняет владельца. |
| BUG-006 | Создаётся и фиксируется заказ `creating` с резервом и неизменным UUID до HTTP-запроса Stripe. Сеть выполняется вне общей блокировки. После ошибки commit используется тот же заказ и ключ идемпотентности. Неизвестные попытки старше 23 часов передаются на сверку, чтобы не создавать повторную сессию после срока хранения ключа. |
| BUG-007 | Администратор может сверить неизвестную сессию, восстановить услугу либо вернуть оставшуюся сумму с причиной, оператором, датами, квитанцией и AuditLog. Повтор операции использует существующую квитанцию. |

Новая история хранит индивидуальные интервалы TOP. Возврат одного заказа не
удаляет другие оплаченные интервалы. Старые агрегированные права, которые
невозможно безопасно разделить, передаются на отдельную проверку. Восстановление
уже выданной услуги сохраняет первоначальный срок и не добавляет бесплатный месяц.

Политика: открытый спор или незавершённый возврат приостанавливает показ;
неистёкшее рекламное место при этом остаётся зарезервированным. Выигранный спор
восстанавливает оставшийся исходный период; полный возврат или проигранный спор
завершает соответствующую услугу. Частичный возврат требует явного решения
администратора. Автоматический пропорциональный возврат не выполняется.

Расширить подписку Stripe webhook: `checkout.session.async_payment_failed`,
`charge.refunded`, `refund.created`, `refund.updated`, `refund.failed`,
`charge.dispute.created`, `charge.dispute.updated`, `charge.dispute.closed`,
