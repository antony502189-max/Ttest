# AI Search — выпуск и передача, 19 ноября 2026

Сайт: https://app.112233.es/. [Краткая инструкция](../AI_SEARCH_USER_GUIDE.md).

Выпускаем существующий рабочий путь: текст/голос → подтверждённые карточки/карта → вход → сохранение → внутренние уведомления. По прямому решению владельца новые расширения и длительные сертификационные работы не задерживают выпуск этой версии. Основной completion plan остаётся источником статусов; полное выполнение A1–A12 этим решением не подменяется.

## Завершающий исправляющий пакет

Кнопки, состояния микрофона, ошибки голоса и причины недоступности теперь используют выбранный ES/RU/EN язык. Исправлены оставшиеся непереведённые пояснение покрытия и кнопки пагинации. Правила записи, одноразовая обработка аудио, квоты, SQL и провайдеры не менялись.

Серверная read-only проверка существующего аккаунта подтвердила ровно один native text request со статусом succeeded/result1, used1/reserved0/limit200 за 18 ноября. Условия сохранённых snapshot дословно равны criteria результата; оба прежний и новый поиски включены. Новый snapshot: одна create receipt, baseline1/current match1, worker fence248/lease clear на срезе. Уведомления0 ожидаемы: уже показанное объявление включено в baseline; новая доставка в этой сессии не имитировалась. Старый поиск не удалён.

Первая проверка ошибочно требовала совпадения intent_hash результата и сохранённого snapshot. Это разные identity/version и разные подписи по контракту. Проверка исправлена на точное равенство criteria и штатный `_decode` каждой подписи; application code сохранения не менялся. Первоначальный отказ не считается дефектом продукта.

## Известные ограничения текущего выпуска

- Поиск использует действующий проверенный cohort13 источников/объектов и строгий локальный разбор поддерживаемых условий; произвольный разговор с внешней LLM не включён. Платный provider и расширение данных не активировались.
- Доставка уведомлений реализована внутри сайта. Подтверждение новой регистрации по email и отдельная email-рассылка не сертифицированы этим выпуском.
- Реальная речь распознаётся локальной Whisper Small. Проверки открытых человеческих записей выполнены, но полнота акцентов/смешанной речи и голосовой p95≤10s не сертифицированы. Пользователь может повторить запись или ввести текст.
- Большие нагрузочные испытания и полный период наблюдения остаются отдельными незавершёнными пунктами. Быстрые локальные проверки их не заменяют.
- Предыдущий live reload check остановлен Windows browser URL policy. Обхода не было; браузерные reload/ownership regressions проходят в контролируемой среде.
