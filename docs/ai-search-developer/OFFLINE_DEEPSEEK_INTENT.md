# Offline DeepSeek intent adapter — 2026-10-27

The adapter implements IntentPatchParser with a required outbound gate, explicit policy and synthetic SecretStr credential. Only HTTPX MockTransport is accepted; no settings, factory, route or worker registers it. This check is an activation barrier, not a process network sandbox: a handler is trusted injected Python and could perform arbitrary I/O. Supplied test handlers perform only local fake HTTP. A real provider still needs minimization, account/privacy/DPA and activation approval. No key or live call is needed here.

Primary references checked on2026-10-27: [JSON Output](https://api-docs.deepseek.com/guides/json_mode/), [Thinking Mode](https://api-docs.deepseek.com/guides/thinking_mode/), [Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/). Requests explicitly set deepseek-flash, nonstreaming JSON output, thinking disabled, bounded tokens, schema and a nonempty illustrative patch. The example is not model-quality evidence. No OpenAI SDK/fallback.

The gate supplies purpose/provider-bound minimized text and typed criteria. No session/user/result IDs, raw conversation history, source payload/URL or SQL enters the envelope. This type and synthetic gate do not certify privacy or sanitization.

Strict set/remove validation rejects duplicate/nonfinite JSON, identity injection, coercion, null removal, overlap, unknown fields, refusal/tools/truncation and malformed output. Shared pets/amenities arrays must be nonempty for hard and soft criteria; removal requires explicit remove. Empty hard rule groups are rejected. Persisted invalid empty collections fail validation instead of broadening search; no automatic repair/backfill or migration.

Empty or effectively unchanged provider patches are PROVIDER_RESULT_INVALID. Existing orchestration releases the reservation with LLM_FAILURE, preserves intent/version, skips card query and debits zero. Pet/amenity ordering and equivalent money formatting cannot manufacture changes. This is the adapter's invalid-interpretation boundary, not a universal clarification policy for every parser. Repeating a committed search has a free result read path. A genuine changed intent with zero matches still costs one successful search. Both outcomes/replay are tested through real PostgreSQL and MockTransport.

Accept-Encoding identity is requested and any non-identity response encoding is rejected before body reads. Unbuffered bodies use aiter_raw; advertised Content-Length and accumulated raw bytes are checked before copying into the adapter buffer. Prefetched unencoded fake fixtures are checked without another body copy. The actual gzip regression represents8MiB decoded data, traps HTTPX decompressor calls, asserts zero reads/closed response, and measures adapter-path traced peak below4MiB. This closes the compression bypass; max_response_bytes is not a total Python process/JSON-object memory guarantee or a bound on allocations inside trusted handlers.

HTTPX phase timeout remains separate from required total_budget_seconds. The monotonic asyncio deadline covers gate, all attempts, waits, body and validation. Clock checks reject late synchronous results even before delivery of the timer callback. External cancellation is preserved. TextSearchExecution rejects a declared parser budget greater than or equal to its running lease. This leaves configuration headroom but does not bound database/query/finalization or approve production budgets; lease fencing remains authoritative. Cooperative cancellation cannot forcibly preempt arbitrary blocking trusted code.

Transient429/5xx/transport errors retry within max_attempts and total deadline, using full-jitter exponential backoff from the explicit retry base. Retry-After seconds and HTTP dates are minimum waits. Valid waits exceeding remaining budget stop without early retry, including huge numeric headers. Invalid headers fall back to jitter. Permanent4xx/redirects fail immediately and redirects are never followed. Bodies, credentials and raw text are not logged or included in fixed private failures.
