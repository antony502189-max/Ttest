ResultsMap accepts an optional keyed serverSource and uses it instead of its ordinary catalog-map loader. There is no error fallback between the two. Source changes abort previous requests; responses from aborted requests cannot replace newer markers. A mismatched AI intent hash fails before markers are returned to the map. Errors clear stale markers and display a scoped visible notice. Remounting by result reference/hash discards the previous selected detail and all map state after a conversational update.
