# Работа над AI Search

При любой задаче, относящейся к AI Search, сначала прочитай [единый план завершения](docs/ai-search-completion-plan.md).

- Продолжай с текущего этапа и следующего действия, указанного в плане. Не составляй новый конкурирующий план и не начинай реализацию для неподтверждённого проекта.
- Связывай задачи с ID этапов S0–S7. Не заменяй незавершённые обязательные задачи новыми улучшениями.
- После каждой сессии обновляй в плане статусы, доказательства проверок, блокеры, журнал и следующее действие. Не объявляй этап готовым без выполнения критериев выхода.
- Новые идеи помещай в отложенный список. Обоснованные изменения основного маршрута фиксируй в журнале версий с причиной и влиянием; прямые новые инструкции пользователя имеют приоритет.
- Не смешивай готовность кода, проверку на стенде и подтверждённую работу выпущенной версии.
- AI Search уже реализуется внутри 112233.es. Эта папка на старом локальном main может не содержать AI-код; сверяй `origin/main` и GitHub до выводов об отсутствии функции. На 03.11.2026 проверен main `4a60e163` с merged PR #403. Не перезаписывай чужие незавершённые изменения для обновления checkout.
- Полное завершение включает текст, голос, сохранение AI-поиска и уведомления после регистрации. Закрытый synthetic текстовый стенд — промежуточный результат. Provider/data/performance/release gates остаются открытыми до доказательств их прохождения.

Эти инструкции относятся к AI Search и не требуют менять порядок независимых задач проекта.
